# Reproducible analysis

Run from the repository root:

```bash
node analysis/analyze-roster.mjs > /tmp/vietprofs-roster-analysis.json
node analysis/history-summary.mjs > /tmp/vietprofs-history-summary.json
```

The first script reads `public/data.json` and reports counts, distributions, coverage fields,
and conservative institution/field observations. The second summarizes public Git history by
commit-message category. The field matcher intentionally mirrors the broad taxonomy in
`src/data.ts` only approximately; manuscript counts for canonical fields should be checked
against the application implementation or regenerated by a TypeScript-aware analysis script.
