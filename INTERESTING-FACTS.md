# Candidate roster observations

All observations are computed from the current roster snapshot and must be worded as “within the
current VietProfs dataset.” Counts below were generated by `npm run analyze`
(`analysis/analyze-roster.ts`, 2026-08-31 snapshot).

1. **Institutional breadth.** Stanford and UC San Diego each have 14 records, followed by Monash
   with 13, the largest current university groups.
   Computation: count records by exact `university`, sort descending. Interesting because it
   shows a directory can reveal institutional clusters without asserting institutional prestige.
   Confidence: High. Caveat: discoverability and search effort vary.

2. **International spread.** The international subset has 334 records across 19 non-U.S. country
   values (20 including the U.S.). Computation: filter `country != United States`, count distinct
   countries. Interesting because expansion has moved beyond a U.S.-only directory. Confidence:
   High. Caveat: country coverage is not uniform.

3. **Field breadth.** The current snapshot maps records to 17 broad fields; health (184), computing
   (147), business/economics (139), and engineering (137) are the four largest. Computation: apply
   the canonical `fieldOf` to `department`, count. Interesting because the maintained data supports
   cross-field browsing. Confidence: High. Caveat: department taxonomy is an operational
   classification.

4. **Same-institution field cluster.** Stanford has 13 health-science records, the Kaiser Permanente
   medical school has nine records currently classified as Others, JAIST has eight computing
   records, and the University of Minnesota and UTS have seven each (health sciences and engineering
   respectively). Computation: group by `university + broad field`. Interesting because
   it identifies local disciplinary clusters. Confidence: High. Caveat: current roster counts only.

5. **Cross-department breadth.** Monash and Stanford each span 12 distinct stored departments;
   UC Irvine spans 11. Computation: group exact `department` values by university. Interesting
   because some university groups are cross-disciplinary rather than single-department. Confidence: High.
   Caveat: department naming granularity affects the count.

6. **U.S. geographic concentration.** California (142) and Texas (76) together contain 218 of 659
   U.S. records (33%). Computation: count U.S. records by `state`. Interesting as a roster map;
   not evidence about the Vietnamese population or causal migration. Confidence: High.

7. **U.S./international field contrast.** Computing is 11% of U.S. entries versus 22%
   internationally; health is 24% versus 8%. Computation: field shares after country split.
   Interesting as a qualified roster comparison. Confidence: Medium. Caveat: selection and coverage
   bias, especially the clinical-track expansion that concentrated in U.S. medical schools.

8. **Appointment diversity.** The snapshot contains five accepted tracks, with 96 Clinical, 68
   Teaching, 37 Emeritus, and 18 Research records alongside 774 Tenure-line records. Computation:
   count `track`. Interesting because inclusion extends beyond one rank vocabulary. Confidence:
   High. Caveat: tracks reflect project policy and evidence.

9. **Evidence/credential coverage.** 751 records have explicit PhD institutions, 549 have PhD
   years, 219 link Scholar, and 127 link personal/lab sites. Computation: field presence counts.
   Interesting because missingness is measurable and is itself a maintenance target. Confidence:
   High. Caveat: presence does not establish correctness.

10. **Longitudinal potential.** The repository history includes more than 650 commits over
    2026-08-15--2026-08-31, among them a 20-batch full-roster refresh and repeated
    additions/corrections. Computation: Git log and snapshot diffs. Interesting because Git
    supplies a partial event history. Confidence: High. Caveat: commit messages are
    not a complete event log and dates reflect repository history.

11. **Health subfields without fragmenting the top taxonomy.** `src/data.ts` derives clinical
    medicine, public health, nursing, pharmacy, dentistry, biomedical research, and medical
    education under Health Sciences. Computation: `healthSubfieldOf`. Interesting because the site
    supports specialty discovery while retaining a stable broad-field filter. Confidence: High.
    Caveat: keyword mapping and overrides can misclassify ambiguous departments.

12. **Runtime freshness of derived facts.** `buildFunFacts` recomputes observations from the passed
    roster rather than loading a stored facts snapshot. Computation: code inspection and tests.
    Interesting because record changes immediately alter the view. Confidence: High. Caveat:
    there is no separate historical fact invalidation ledger.

13. **Deduplication is a lived operation.** History records duplicate University of Dayton entries,
    name suffix corrections, and roster-wide university canonicalization. Computation: cited Git
    commits. Interesting because entity resolution is not only a preprocessing step. Confidence:
    High. Caveat: affected records are not labeled with a structured duplicate-event type.

14. **Negative discovery is represented operationally.** A Taiwan country sweep commit records no
    additions and a thorough negative check. Computation: Git commit `9b31b95`. Interesting because
    bounded search can produce auditable non-addition results. Confidence: Medium. Caveat: a
    negative search is not proof of absence.

15. **Awards are separately constrained.** Honors-bearing records total 182, while policy excludes
    routine local teaching/service/community awards and requires source-backed field-level
    distinctions. Computation: count `honors` and read policy. Interesting because derived award
    views have their own evidence and scope rules. Confidence: High. Caveat: honor completeness is
    unknown.
